# Retouch 发布

macOS 修图 App Retouch 的安装包、自动更新清单和 AI 模型。源代码不在这里。

## 安装

1. 到 [Releases](../../releases/latest) 下载 `Retouch-版本号.zip`，解压后把 Retouch 拖进“应用程序”
2. 目前还没有经过苹果公证：**第一次打开请在 Finder 里右键 → 打开**，之后正常双击即可
3. 需要 macOS 14 或更新版本，推荐 Apple 芯片

之后的新版本可以在 App 菜单“检查更新…”里自动升级。

## AI 模型

抠图、消除、点选物体用到的模型在 [models-v1](../../releases/tag/models-v1) 里，App 会按需自动下载，不用手动处理。
各模型的许可见那里的 `THIRD_PARTY_NOTICES.md`。
